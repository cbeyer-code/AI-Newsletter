## Highlights of the Week

Ornith 1.5 models were released, which are open-weight models built on top of QWEN3.5.  
They outperform a lot of models of similar and bigger size, including QWEN 3.6.  
I also find them interesting as they claim to use self-improvement methods:  
‘Ornith-1.5 extends the self-scaffolding framework introduced in Ornith-1.0 into a more complete self-improvement loop: the model **proposes new tasks, generates task-specific scaffolds, and produces solution rollouts** for reinforcement learning, continuously creating new learning experiences from which it can improve.’  
<https://ornith.ai/ornith_1_5.html>  
I only tried ornith1.5-35B-A3B, and it gives me amazing token speed, has vision and seems really great at agentic coding for its size. I managed to run it via **Unsloth Desktop, which didn’t hang up a single time (>100k output tokens)** but actually vibe coded a whole 3d shooter in one shot.   
The controls were reversed, and it froze when an enemy exploded, but otherwise it still  
worked out of the box. Four prompts later, I had that fixed, added muzzle flash, and it also one-shotted some synthwave-style music. Really recommend trying these models and the game :-)  
<https://ornith35b-shooter.netlify.app/>  
<https://huggingface.co/ornith-ai/Ornith-1.5-35B-A3B>  
  
In this post, Professor Jie Tang, founder of one of the Chinese AI labs, explains the different dimensions that can be scaled in LLMs and how the focus changed over time. A wonderful read with a lot to learn from.  
<https://x.com/jietang/status/2089941544581403107>  
  
Another wonderful interview (12min) with Yuval Harari was done by The Economist, where he touches on many important points. I found it especially interesting that one of the big dangers of AI is that it can mass-produce trust and intimacy, which can be exploited a lot for marketing or other reasons like propaganda and manipulation.  
<https://www.youtube.com/watch?v=ARdnl2kjmRU>

## Models, Benchmarks and Hardware

OpenAI built its own custom inference chip called Jalapeño, which seems to outperform almost any other chip for that task when focusing on the wattage used. So far, this is a lot of marketing as people cannot readily order and try these chips. I would also read the following statement as PR until proven otherwise, but big if true:  
‘AI played a direct role in Jalapeño’s development…  by exploring implementations, shortening design, measurement, and verification loops, and continuously iterating on model workloads. AI also helped optimize the chip’s arithmetic circuits…’  
<https://openai.com/index/jalapeno-first-results/>

DeepSeek is adding vision to their recent models, which was one of the main missing features that people asked for. They released DeepSeek-V4-Flash-Vision-Exp, where you can try it already. Unfortunately, it will only be made open-weights once it is no longer experimental.  
<https://x.com/deepseek_ai/status/2090730032574631962>  
Here is a nice post showing how to run DeepSeekV4-Flash on a single Spark.  
<https://x.com/MiaAI_lab/status/2090737183099384193>

Qwen3.8-Flash will be released today, which might be very interesting as people love  
DeepSeekV4-Flash as the most intelligent model given the cost to run it, and I would  
assume that the QWEN team aims to outperform it.  
<https://modelscope.cn/models/Qwen/Qwen3.8-Flash-Next>  
  
MazeBench is a benchmark a bit similar to ARC-AGI 3, where models have to collect gems in mazes and solve riddles. Without harnesses, frontier models from Anthropic and OpenAI can only solve 1%; with harnesses, this goes up to 13%. Other models struggle to do anything or try to cheat, which you can see in the second link. This benchmark shows again that human and machine intelligence are still vastly different in their capabilities.   
<https://mazebench.com/leaderboard/ai?mode=ascii&tools=1&metric=gems>  
<https://x.com/Artemonim/status/2091973014967423188>  
  
Arduino is releasing a new platform, Ventuno Q, especially for building AI-based hardware projects, e.g., a translator device, or anything with object recognition.  
It has 16GB of shared RAM, which is actually amazing and enables running multiple small models at the same time, e.g., Whisper for STT, Gemma 4 as an LLM, and QWEN 3-0.6B TTS.  
You could build a real Furby :-)  
<https://www.arduino.cc/product-ventuno-q>  
<https://en.wikipedia.org/wiki/Furby>
