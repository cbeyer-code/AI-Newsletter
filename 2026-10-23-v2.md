**AI is playing the Runescape MMO**  
This is a wonderful presentation by Max Bittker about research on agentic behaviour in a fun and interesting setting of an MMO computer game, where players have to learn skills, acquire and trade resources and equipment, and fight monsters. There is a server where all player characters are run by AI agents, which lets him see how they set and pursue goals and how they interact with other AIs. The speaker reports that such sandbox environments are wonderful because you can run tons of trial-and-error experiments and see how new policies or techniques change the agent’s behaviour. He points out that almost any behaviour that can be turned into a benchmark can be hill-climbed and learned by AI, and he shows how to build your own benchmarks in a unified way using Harbor. His main learnings on how to create  a good benchmark are:   
Make it hard (so it doesn’t get easily saturated), verifiable, cheap, ensure that the desired behaviour is encoded and cannot be reward-hacked easily, and make it interesting for other people so it gets used.  
My favourite part is when he shows how a GPT run alchemist turns into a scammer when he sees his profit margin dwindle 😆   
<https://github.com/harbor-framework/harbor>  
<https://maxbittker.github.io/runebench/>

**AI developing creative game ideas**  
A game studio claimed that AI can have no original ideas. Someone pointed out that you can actually create novel ideas by mapping all existing games and their descriptions onto a map and then exploring regions of the map that are empty by turning embeddings back into descriptions of non-existing games that aren’t too similar to nearest neighbours. Another user had Claude do it and visualise it, which looks fantastic and is a beautiful data science project. Voilà, we have mathematically guided creativity. The real art is to figure out which of these new ideas are actually viable and fun gameplay-wise.  
<https://x.com/re_skob/status/2113043120128483349>  
  
**Anthropic’s proactive Agent**  
Anthropic is slowly rolling out Duet, which is a proactive agent that will not only wait for your input but work by itself in your absence and then update you. I think the main idea is that you have a worker who looks for new, sensible tasks to do and requests them instead of hanging around idly once the current job is done. This could be huge in the long run once it works reliably, moving us closer to having a private assistant. ‘Remember today is the deadline to register for the exams. Should I sign you up for all subjects that you are currently taking?… I’ve done the registration and also prepared all the dates to be added to your calendar. Should I go ahead and add them?’

## Safety

**Self-training into misalignment**  
Some researchers showed that if you recursively retrain a model on outputs it deems safe, it will become more and more misaligned over time, which kind of sucks when we want AI to create better AI, which creates better AI…  
<https://x.com/Karim_abdelll/status/2112589993537569128>
